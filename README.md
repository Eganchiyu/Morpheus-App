# Morpheus-App
一个可以帮助用户及时记录、回忆梦境并发现相关内容的app

## Version 0.1
第一版计划实现以下功能：
1、用户可以设置每日梦境记录提醒通知的发送时间
2、用户可以使用文字记录梦境
3、用户可以编辑和删除梦境记录
4、用户可以通过日历查看过去的记录
5、数据优先保存在本地设备

## Future Features
未来可能加入：
1、获取智慧型手表的睡眠数据，自动发送提醒通知
2、AI梦境画报
3、AI周期梦境总结
4、电影、音乐和文学作品推荐
5、云端同步
